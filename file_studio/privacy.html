Your files never reach us, because there is no us to reach.

File Studio is a static website. It has no server that can receive a file, no database that can store one, and no account that could tie one to you.

What happens when you drop in a file

Your browser reads the file straight from your disk into the memory of this tab, the same way a photo viewer does. The tool's JavaScript works on those bytes, hands you the result as a download, and forgets everything when you close the tab or hit reload.

There is no step in between where the file travels somewhere. Nothing is queued, cached on a server, scanned, or kept "for 2 hours" the way most online converters do.

The test you can run yourself: load this site, switch off your Wi-Fi, then merge or convert a file. Everything still works — because nothing needed a connection in the first place.

What we collect

  • Files: none. They are never transmitted.
  • Accounts: none. There is nothing to sign up for.
  • Analytics and trackers: none. No Google Analytics, no pixels, no fingerprinting scripts.
  • Cookies: none set by File Studio.

The one network request we do make

Some tools lean on well-known open-source libraries — pdf-lib and pdf.js for PDFs, Tesseract.js for text recognition, SheetJS for spreadsheets, mammoth for Word files, JSZip for archives. Those libraries are fetched from a public CDN (cdnjs) the first time you open a tool, plus the web fonts from Google Fonts.

That request downloads code to you. It carries your IP address and browser, as any request for a file does, and nothing else — your document is not part of it and is never sent anywhere. If you'd rather not touch a CDN at all, download the repository and drop the library files in locally; every tool then runs completely offline.

What stays on your device

Nothing is written to storage unless a tool clearly says so. Results are handed to you as ordinary downloads, saved wherever your browser saves things. Deleting them is between you and your file manager.

What this cannot protect you from

Being honest matters more than sounding airtight:

  • If your own computer is compromised, no in-browser tool can help.
  • Browser extensions can read pages you have open, including this one.
  • A redacted or flattened PDF is only as private as the copy you share — keep the original somewhere safe.
  • If you host this site yourself, whoever hosts it controls what is served. Check the code you deploy.
