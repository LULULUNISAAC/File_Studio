Output

Be aware. PowerPoint files don't carry a rendered picture of each slide, so the text and images are re-laid out in a clean template rather than reproduced exactly. Animations, charts, SmartArt and speaker notes are left out. For a pixel-perfect PDF, use PowerPoint's own export.
