Nothing you open here is uploaded, tracked, or stored.

File Studio has no server and no backend — it's a static site. Every tool runs as JavaScript inside your own browser tab, so your files are read, processed and downloaded on your device only. Closing the tab clears everything. There's nothing to sign in for, and nothing sent anywhere for us — or anyone else — to see.

— No file uploads — No accounts — No analytics or trackers — Open source

Built to be looked at, and looked through.

File Studio is a small, static toolkit — the code for every tool is sitting right in this repository. If you can read JavaScript, you can confirm exactly what happens to a file the moment you drop it in.
